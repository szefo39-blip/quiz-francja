🇫🇷 BONJOUR FRANCE • PROJEKT 2026

O stronie

„Bonjour France” to interaktywna strona edukacyjna przygotowana z okazji Dnia Języków Obcych 2026. Jej celem jest połączenie nauki języka francuskiego z poznawaniem Francji, jej kultury, historii, symboli i ciekawostek — w lekkiej i angażującej formie.

HTML CSS JavaScript AI
💻

W jakim języku powstała?

Strona została napisana w językach HTML, CSS i JavaScript, przy pomocy sztucznej inteligencji. HTML odpowiada za strukturę strony, CSS za wygląd, a JavaScript za quiz, gry, punktację i interakcje.

🔒

Co z danymi?

Gry dodatkowe nie zapisują wyników do rankingu ani nie tworzą profilu użytkownika. Strona nie zbiera danych takich jak hasła, adresy czy dane kontaktowe. Główny quiz jest wyjątkiem — jego ranking zapisuje podane imię oraz wynik, aby uczestnicy mogli zobaczyć wspólną klasyfikację.

🧠

Dlaczego nie przechowujemy więcej danych?

Strona została zaprojektowana jako projekt szkolny, dlatego nie ma potrzeby gromadzenia informacji o użytkownikach. Ograniczenie danych zwiększa prywatność i sprawia, że strona skupia się na nauce i zabawie, a nie na zbieraniu informacji o osobach korzystających ze strony.

🌍

Po co powstała?

Strona powstała specjalnie z okazji Dnia Języków Obcych, aby pokazać, że nauka języka może być ciekawa, nowoczesna i interaktywna. Motywem przewodnim jest Francja oraz język francuski.
